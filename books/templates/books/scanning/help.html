Scanning folders

Add folders on the Scanning page to discover new books. Each folder has a content type (ebooks, comics, or audiobooks) and a default language.

  • Quick scan discovers files and extracts local metadata from the files themselves.
  • Deep scan additionally queries external providers (Google Books, Open Library).
  • Rescan re-queries external providers for books that already have metadata.
Review and rename

After scanning, review each book's metadata and confirm it, then rename and organise the file against your naming template.

  • Review books with the books list and per-book metadata editor.
  • Preview the new file name and location before renaming.
External providers

External lookups are rate limited. The API status page shows the current quota usage and any source that is temporarily unavailable.
